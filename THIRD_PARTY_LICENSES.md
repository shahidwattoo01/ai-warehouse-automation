# Third-party licences

The platform is built on open-source software. This file lists the main dependencies, their
licences and what each licence means for this project. Versions are those pinned in
`requirements.txt` and `apps/frontend/package-lock.json`. (Summary for orientation, not legal
advice: for commercial use, have the licences reviewed.)

## ⚠ Licence that needs attention: Ultralytics YOLO (AGPL-3.0)

| Package | Version | Licence | Used for |
|---|---|---|---|
| `ultralytics` (YOLO11) and its pretrained weights | 8.4.178 | **AGPL-3.0** | Phase 5 object detector (`ai/computer_vision/live.py`, notebooks 09 and `cloud/train_yolo_colab.ipynb`) |

**What AGPL-3.0 means here**

* Using it for this training project, a portfolio, research or a demo: **free**.
* If the software is **distributed or offered to others over a network** (for example as a
  hosted service), the **complete source code of the project** must be made available under
  AGPL-3.0 as well.
* For **commercial use without publishing the source**, Ultralytics sells an
  **Enterprise Licence** (paid, price on request).
* **Alternatives with permissive licences**, if the AGPL terms do not fit: torchvision detection
  models (Faster R-CNN, RetinaNet, SSD; BSD-3-Clause) or RT-DETR implementations under
  Apache-2.0. The detector sits behind one module (`ai/computer_vision/live.py`) and one API
  (`/api/v1/vision/detect`), so it can be replaced without changing the rest of the platform.

## Data and models

* **Datasets** (dataset v3, camera images, commands) are generated by this project's simulator: no
  third-party or personal data.
* **Pretrained weights:** YOLO11s was pretrained by Ultralytics on the COCO dataset (COCO
  annotations: CC BY 4.0); the weights follow the Ultralytics AGPL-3.0 licence above.
* **DistilBERT** (`distilbert-base-uncased`, Hugging Face): Apache-2.0. The fine-tuned copy in
  `models/nlp_distilbert_v1/` may be used and redistributed under the same terms (keep the licence
  notice). It was pretrained on English Wikipedia and BookCorpus.
